# Week-3-Practical-Lab-Roles-Responsibilities-and-Accountability-in-Security-Governance
# About
This project presents a cybersecurity governance transformation for TechGlobal, an organization with approximately 2,500 employees across five offices. Assessment focuses on strengthening security governance, clarifying accountability, improving risk escalation, and reducing conflicts caused by concentrated decision-making authority.

# Project Overview
The document identifies governance gaps, including limited Board visibility, the absence of a formal cross-functional governance committee, inconsistent business-unit security decisions, unclear risk ownership, and weak escalation pathways.
It proposes a structured governance architecture involving the Board, CEO, CISO, CRO/Risk, Legal/Compliance, Finance, HR, IT, and Business Unit Leaders. The model separates security oversight, risk challenge, business ownership, and technical implementation.

# Key Deliverables
1. Governance gap assessment and stakeholder map
2. Security governance organization structure
3. Role, responsibility, and authority profiles
4. Security Governance Committee Terms of Reference
5. RACI accountability matrix
6. Cyber-risk escalation workflow
7. Segregation-of-duties and accountability register
8. Decision recording and assurance guidance

# Governance Framework
The approach is informed by the NIST Cybersecurity Framework (CSF) 2.0 and COBIT 2019. It emphasizes clear decision rights, independent risk challenge, documented risk acceptance, effective escalation, and traceable governance decisions.

# Expected Outcome
The transformation provides TechGlobal with a governance structure that supports cybersecurity decision-making, stronger accountability, improved Board oversight, and better management of enterprise cyber risks.
